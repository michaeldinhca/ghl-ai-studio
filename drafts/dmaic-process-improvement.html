DMAIC process improvement

DMAIC: a five phase method to fix processes for good

DMAIC is the Six Sigma cycle for improving an existing process: Define, Measure, Analyze, Improve, Control. Here is exactly what we do in each phase, the tools we use and what you get at the end.

FAQ

DMAIC questions

What does DMAIC stand for?

DMAIC stands for Define, Measure, Analyze, Improve and Control. It is the five phase problem solving cycle at the heart of Six Sigma, used to improve an existing process.

What is the difference between DMAIC and DMADV?

DMAIC improves a process that already exists. DMADV (Define, Measure, Analyze, Design, Verify) is used to design a new process or product from scratch.

Which tools are used in each DMAIC phase?

Common tools are a project charter and SIPOC in Define, value stream maps and measurement system analysis in Measure, Pareto charts, fishbone diagrams and hypothesis tests in Analyze, pilots and mistake proofing in Improve, and control charts with a control plan in Control.

How do you know a DMAIC project worked?

We compare the controlled process to the baseline captured in Measure, using the same metric and the same data source. If the gain does not hold for at least one full cycle, the project is not closed.
