# ghl-ai-studio

Test build of **NGYN AI Frontier**, a Lean Six Sigma consulting site for GHL AI Studio, made with the `ghl-ai-studio-builder` skill.

- Status: Phase 2 mockup (single-file drafts). Phase 3 (TanStack Start conversion into `src/`) comes after approval.
- Edit copy in `_src/build.py`, then run `python _src/build.py` and the skill's `build_preview.py .`
- `index.html` and the sibling pages are generated. Do not hand-edit them.
- All contact details are mock values. The results figures are illustrative.
